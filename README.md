# PicShelf

Настольное приложение для сортировки фотографий в Linux. Открывает папку вместе с подпапками, показывает предпросмотр и помогает переносить выбранные снимки.

## Установка и запуск на Debian и Ubuntu

```bash
sudo apt install git python3-tk python3-pil.imagetk
git clone https://github.com/velikoross/picshelf.git
cd picshelf
/usr/bin/python3 picshelf.py
```

## Работа с фотографиями

1. Нажмите **Открыть папку…**. В списке появятся относительные пути к файлам JPEG, PNG, WebP, TIFF, BMP и GIF. Щёлкните по снимку для предпросмотра.
2. Нажмите **Найти дубликаты**, чтобы увидеть группы точных копий. Программа сравнивает размер и SHA-256 содержимого. Пережатые снимки и версии с изменёнными EXIF считаются разными. Кнопка **Все фото** возвращает полный список.
3. Выделите файлы с помощью **Ctrl** или диапазон с помощью **Shift**. Нажмите **Переместить выбранные…** и выберите каталог назначения. Все выбранные файлы окажутся непосредственно в нём. При совпадении имён PicShelf добавляет суффикс, например `IMG_001 (1).jpg`. Снимки, которые уже находятся в каталоге назначения, пропускаются.

Работает локально. Символические ссылки при сканировании пропускаются. После переноса список обновляется. Если каталог назначения расположен внутри открытой папки, перемещённые снимки появятся с обновлёнными путями.
